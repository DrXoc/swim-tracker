Google Sheets Apps Script API Integration

Connect your web app to Google Sheets to backup roster data and power the Swimmer Portal.

Google Apps Script Setup Instructions:

  1. Open a Google Sheet and click Extensions > Apps Script.
  2. Paste the provided Code.gs backend script into the editor.
  3. Click Deploy > New Deployment. Select type Web App.
  4. Set Execute as: Me and Who has access: Anyone.
  5. Copy the generated Web App URL and paste it into the field above.
