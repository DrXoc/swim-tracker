Google Sheets Backup Integration

Paste your Google Apps Script Web App Deployment URL below to back up all team attendance records automatically to Google Sheets.

How to setup Google Sheets Sync:

  1. Create a new Google Sheet in your Google Drive.
  2. Go to Extensions > Apps Script.
  3. Replace any existing code with the Google Apps Script snippet provided below.
  4. Click Deploy > New Deployment, choose type Web App.
  5. Set Execute as: Me, and Who has access: Anyone.
  6. Copy the Web App URL and paste it into the field above!
