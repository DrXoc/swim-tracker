Attendance & Penalty Mathematical Engine

Club Swimmers Standard Commitment Based

Attendance % = clamp(0, 100, round(( Total Net Earned / (Active Weeks × Commitment) ) × 100))

  • Active Weeks: Number of unique calendar weeks active in system starting from Join Date.
  • Weekly Credit: min(Present Count, Commitment) - (NoComm Count × 1)
  • Timezone Protection: Dates are parsed at local midnight to ensure server & browser alignment.
Seasonal Swimmers Standard Schedule Based

Attendance % = clamp(0, 100, round(( Net Score / Expected Mandatory Events ) × 100))

  • Present (+1): +1 Earned Credit
  • Absent Comm (0): 0 Earned Credits (out of 1 expected)
  • No Comm (-1): -1 Net Credit (Double penalty deduction)
  • Excused: Exempt (reduces total expected mandatory count by 1)
  • Holiday / Bonus (+1): +1 Bonus Credit if present (does not increase expected count)
Varsity Letter Criteria
  • Qualified: Swim Attendance ≥ 85% AND Strength Compliance ≥ 85%
  • At Risk: Swim Attendance ≥ 75% AND Strength Compliance ≥ 75% (Below 85%)
  • Ineligible: Either Swim or Strength < 75%

Google Apps Script Deployment

To enable 2-way cloud sync with your Google Sheet, create a new script under Extensions > Apps Script in Google Sheets and paste this handler:

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    sheet.clear();
    sheet.appendRow(["ID", "Name", "Grade", "Team", "Category", "PIN", "Swim Att %", "Strength %", "Varsity Status"]);
    
    data.swimmers.forEach(function(s) {
      var stats = s.computedStats || {};
      sheet.appendRow([s.id, s.name, s.grade, s.gender, s.type, s.pin, stats.attPct + "%", stats.strPct + "%", stats.status]);
    });
    
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Deploy as Web App, execute as "Me", and set access to "Anyone". Paste the deployment URL in Coach OS Reports tab.
